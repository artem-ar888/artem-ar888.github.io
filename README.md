# Резюме — Артем Арафаилов

Одностраничный сайт‑резюме с адаптивной вёрсткой и отдельной версией для печати. Сайт опубликован на GitHub Pages.

## Сайт проекта

🔗 [Ссылка на сайт](https://artem-ar888.github.io/)

## Что есть в проекте

- **HTML5 / CSS3**: семантическая разметка, Grid/Flex, адаптивность под мобильные устройства.
- **JavaScript**: минимальный объём — только вспомогательные функции.
- **Версия для печати**: отдельный стиль через `@media print` — скрываются кнопки, ссылки, бейджи.
- **Кнопка «Скачать PDF»**: вызывает `window.print()`, открывая стандартное диалоговое окно браузера, где пользователь может сохранить страницу как PDF.
- **Иконки**: все иконки нарисованы в Inkscape. UI‑иконки (одноцветные) встроены напрямую в JavaScript; в репозитории лежит только один SVG‑файл — многоцветный favicon.
- **Чистый код**: без сторонних конструкторов и тяжёлых библиотек; структура построена на понятных блоках и переиспользуемых стилях.

## Особенности реализации

- Печать в PDF без сторонних библиотек: только нативные возможности браузера и CSS.
- При печати отключаются интерактивные элементы и ссылки, чтобы не мешали при распечатке.
- UI‑иконки хранятся как inline‑SVG в JS — меньше файлов и запросов, гибкое управление цветом и размером.
- Аккуратная типографика и читаемые отступы.

## Как запустить локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/artem-ar888/artem-ar888.github.io.git
   ```
2. откройте `index.html` в любом браузере.
